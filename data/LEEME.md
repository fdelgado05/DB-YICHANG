# Carpeta de datos

Sube aquí el Excel de auditoría (`.xlsx` o `.xlsm`). Al subirlo, GitHub regenera el dashboard
automáticamente en uno o dos minutos (pestaña **Actions** → "Actualizar dashboard").

Si hay varios Excel en esta carpeta, se usa el último que subiste.

El Excel debe mantener estas hojas:
- **BASE GENERAL** (con la columna MES): PDV, POP, apreciación y competencia.
- **BASE PRECIOS (…)** (con la columna MES): precios.
- **BASE AGO**, **BASE SEP**, **BASE OCT**…: solo se usan para las fechas de cada visita.

Cada mes nuevo que aparezca en la columna MES se agrega como una opción en el filtro "Mes".
